Unit 6: Web Technology I

Internet basics: The internet is a global network of interconnected computers that communicate using standardized protocols to share information and resources. It enables services such as web browsing, email, file transfer, and online communication, connecting billions of devices worldwide.

Web browsers: A web browser is application software used to access, retrieve, and display content on the World Wide Web. Popular browsers include Google Chrome, Mozilla Firefox, and Microsoft Edge, which interpret web page code and render it visually for users to interact with.

HTML fundamentals: HTML (HyperText Markup Language) is the standard markup language used to create the structure and content of web pages. It uses a system of tags and elements to define headings, paragraphs, links, images, and other components that browsers interpret to display a web page.

Website structure: Website structure refers to how web pages are organized, linked, and navigated within a site. A well-structured website typically includes a home page, navigation menus, and logically linked subpages, making it easier for users to find information and for search engines to index content.
