NEB Class 11 Computer Science Syllabus

Unit 1: Computer System

Introduction to computer: A computer is an electronic device that accepts data as input, processes it according to a set of instructions, and produces meaningful output. It is characterized by speed, accuracy, storage capacity, versatility, and automation. Computers are used in almost every field today, including education, business, healthcare, communication, and entertainment.

Evolution: Computers have evolved through several generations, starting with mechanical calculating devices like the Abacus and moving to vacuum tube-based first-generation computers, transistor-based second-generation computers, integrated circuit-based third-generation computers, microprocessor-based fourth-generation computers, and today's fifth-generation computers based on artificial intelligence. Each generation brought improvements in speed, size, cost, and reliability.

Classification: Computers can be classified based on size (supercomputer, mainframe, minicomputer, microcomputer), based on purpose (general purpose and special purpose), and based on data handling (analog, digital, and hybrid computers). Analog computers process continuous data, digital computers process discrete data, and hybrid computers combine both features.

Mobile computing: Mobile computing refers to the use of portable computing devices such as laptops, tablets, smartphones, and wearable devices that allow users to access information and perform tasks while moving. It relies on wireless communication technologies like Wi-Fi, Bluetooth, and mobile networks to stay connected without being tied to a fixed location.

Computer architecture: Computer architecture refers to the internal design and organization of a computer system, including how the CPU, memory, and input/output devices are structured and interact with each other. It defines how instructions are executed and how data flows between different hardware components to perform computing tasks efficiently.

I/O devices: Input/output devices allow communication between the user and the computer. Input devices such as keyboard, mouse, scanner, and microphone are used to enter data into the computer, while output devices such as monitor, printer, and speaker are used to display or present processed results to the user.

Microprocessor: A microprocessor is the central processing unit of a computer built on a single integrated circuit chip. It performs arithmetic, logical, control, and input/output operations by fetching, decoding, and executing instructions. Its performance is often measured by clock speed, word size, and number of cores.

Bus system: A bus system is a set of physical connections (wires or circuits) used to transfer data, addresses, and control signals between different components of a computer. It typically consists of a data bus for transferring actual data, an address bus for specifying memory locations, and a control bus for coordinating operations.

Primary and secondary memory: Primary memory, including RAM and ROM, is directly accessible by the CPU and used for temporary or permanent storage of data needed during processing. Secondary memory, such as hard disks, SSDs, and optical disks, provides long-term, non-volatile storage for large amounts of data even when the computer is powered off.
