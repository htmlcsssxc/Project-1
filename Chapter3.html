Unit 3: Computer Software and Operating System

System software: System software is a type of software designed to manage and control computer hardware so that application software can perform tasks efficiently. It acts as an intermediary between the hardware and the user, and includes operating systems, device drivers, and utility programs.

Application software: Application software refers to programs designed to help users perform specific tasks such as word processing, data analysis, browsing the internet, or playing games. Unlike system software, application software directly interacts with the end user to fulfill particular needs.

Operating system functions: An operating system performs several essential functions, including managing computer memory, controlling process execution, handling file storage and retrieval, and coordinating input/output devices. It provides a user interface and ensures that hardware resources are used efficiently and securely.

Types of operating systems: Operating systems can be classified into several types based on how they manage tasks, including batch operating systems that process jobs in groups, time-sharing systems that allow multiple users simultaneous access, real-time systems that respond within strict time constraints, and distributed systems that manage multiple interconnected computers.

Process management: Process management is a core function of the operating system that involves creating, scheduling, and terminating processes, as well as allocating CPU time and resources among multiple running programs. It ensures that the system runs smoothly by managing multitasking and preventing conflicts between processes.
