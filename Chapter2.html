Unit 2: Number System and Conversion, Boolean Logic

Decimal, binary, octal, hexadecimal conversion: Computers work internally with different number systems. The decimal system (base 10) is used by humans, binary (base 2) is used internally by computers, octal (base 8) and hexadecimal (base 16) are used as shorthand representations of binary values. Conversion between these systems is essential for understanding how data is stored and processed at the hardware level.

Binary arithmetic: Binary arithmetic involves performing mathematical operations such as addition, subtraction, multiplication, and division using only two digits, 0 and 1. These operations follow specific rules similar to decimal arithmetic but are simpler since only two possible digit values exist, forming the basis of all computer calculations.

Complement methods: Complement methods, including 1's complement and 2's complement, are techniques used to represent negative numbers in binary form and to simplify subtraction operations by converting them into addition. 2's complement is widely used in modern computer systems because it allows a single addition circuit to handle both positive and negative numbers.

Boolean algebra: Boolean algebra is a branch of mathematics that deals with logical values true and false, represented as 1 and 0. It uses logical operators such as AND, OR, and NOT to describe relationships between binary variables and forms the mathematical foundation for designing digital circuits and logic systems.

Logic gates: Logic gates are the basic building blocks of digital electronic circuits that perform logical operations on one or more binary inputs to produce a single binary output. Common gates include AND, OR, NOT, NAND, NOR, XOR, and XNOR, each following its own truth table to determine output based on input combinations.

Boolean laws: Boolean laws, such as commutative law, associative law, distributive law, and De Morgan's laws, are rules used to simplify complex Boolean expressions and logic circuits. Simplifying expressions using these laws helps reduce the number of gates needed in a circuit, making it more efficient and cost-effective.
